## Planning site brief

A local tool that turns one Hong Kong site into a printable English brief: the zoning and plan notes, what surrounds the site, which guidelines are triggered, and the application path. A figure that is not in the official material stays unchecked.

[Read the note](https://github.com/wilsonlaw492/planning-site-brief)
