# Wilson Law

Town planner in Hong Kong. I work on site appraisal and development-potential research, and I build small tools to make that work faster and easier to check.

## Planning Site Brief

A Python tool that reads Hong Kong statutory plans and planning guidelines and drafts a site brief: zoning and plan notes, surrounding uses, relevant guidelines, and the likely application route. Every point in the brief cites the document it came from.

→ [Project page](https://github.com/wilsonlaw492/planning-site-brief)

**Tools:** Python · pdfplumber · SQLite
